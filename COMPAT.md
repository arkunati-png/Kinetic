# Kinetic compatibility layer

Everything here lives in `kinetic/` (new files) plus small, clearly marked
additions to a few musl headers. Build without it using
`./configure --disable-compat`; the result has none of these files, headers
or symbols.

## What Kinetic adds over musl 1.2.5

| Area | Provided | Notes |
|------|----------|-------|
| `<sys/cdefs.h>` | `__BEGIN_DECLS`, `__THROW`, `__GNUC_PREREQ`, `__glibc_likely`, `__nonnull`, ... | Header only. Widely `#include`d by autotools-era code. |
| `<sys/queue.h>` | `SLIST`, `LIST`, `STAILQ`, `TAILQ`, `CIRCLEQ` | Header only; original implementation of the traditional interface. |
| `<sys/tree.h>` | Red-black trees (`RB_*`) and splay trees (`SPLAY_*`) | Header only; generated by macros. Randomized tests check the red-black invariants. |
| `<error.h>` | `error`, `error_at_line`, `error_message_count`, `error_one_per_line`, `error_print_progname` | GNU coreutils-style diagnostics. |
| `<execinfo.h>` | `backtrace`, `backtrace_symbols`, `backtrace_symbols_fd` | Uses the compiler's unwinder (`_Unwind_Backtrace`) if the program links one; otherwise reports only the caller. Symbol names need a dynamically linked program (`dladdr`). |
| `<obstack.h>` | Full obstack API incl. `obstack_printf` | Used by gcc, binutils, make, m4, bison. |
| `<fts.h>` | `fts_open`, `fts_read`, `fts_children`, `fts_set`, `fts_close` | Physical/logical walks, cycle detection, sorting, `FTS_SKIP`/`FOLLOW`/`AGAIN`, `FTS_XDEV`, `FTS_SEEDOT`, `FTS_NOSTAT`. Never changes the working directory (see below). |
| `<argp.h>` | `argp_parse`, `argp_help`, `argp_usage`, `argp_error`, `argp_failure`, `argp_state_help`, child parsers, `--help` / `--usage` / `--version` | Option clusters, abbreviations, aliases, optional arguments, getopt-style permutation, the `ARGP_KEY_*` protocol. See below for differences. |
| `<gnu/libc-version.h>` | `gnu_get_libc_version`, `gnu_get_libc_release` | Return `kinetic-X.Y.Z` / `kinetic`. They deliberately do **not** pretend to be glibc. |
| `<malloc.h>` | `mallinfo`, `mallinfo2`, `malloc_stats` | **Real numbers** with the default allocator, computed on demand by walking allocator metadata (no cost on `malloc`/`free`). Approximate under concurrency. `mallopt` is accepted and ignored; `malloc_trim` is a no-op returning 0. With a non-default allocator the counters read zero. |
| `<ucontext.h>` | `getcontext`, `setcontext`, `makecontext`, `swapcontext` | musl declares these but does not implement them. **x86_64 only.** |
| `<pthread.h>` | `pthread_mutex_clocklock`, `pthread_cond_clockwait`, `pthread_rwlock_clockrdlock/wrlock`, `pthread_clockjoin_np`, `pthread_yield` | glibc 2.30+ APIs. Implemented by converting the deadline between `CLOCK_REALTIME` and `CLOCK_MONOTONIC`; other clocks return `EINVAL`, as in glibc. |
| `<semaphore.h>` | `sem_clockwait` | As above. |
| `<unistd.h>` | `close_range`, `CLOSE_RANGE_*` | Needs Linux 5.9+ (5.11 for `CLOEXEC`); `ENOSYS` otherwise. |
| `<sys/pidfd.h>` | `pidfd_open`, `pidfd_getfd`, `pidfd_send_signal` | Needs Linux 5.3+ / 5.6+. |
| `<stdlib.h>` | `rpmatch`, `canonicalize_file_name` | |
| `<features.h>` | `__KINETIC__`, `__KINETIC_MAJOR__/MINOR__/PATCH__` | Feature-test macro. Kinetic does **not** define `__GLIBC__`. |

## Behavior notes and limitations

* **fts never changes directory.** Every entry is reached by its full path, so
  `fts_accpath == fts_path`, exactly as with `FTS_NOCHDIR`. This makes fts safe
  in threaded programs. Code that only uses `fts_accpath`/`fts_path` (all
  portable code) behaves identically; code that assumes the process cwd moves
  as it walks does not. Paths longer than `PATH_MAX` fail with the usual errors.
* **argp output is GNU-style, not byte-identical.** Help layout (column 29,
  `Usage:` forms, group headings, the "Mandatory or optional arguments" note)
  follows GNU argp, but group-number ordering of options is not implemented
  (options appear in declaration order), and `argp_domain` message translation
  is ignored. Error messages go through `argp_error` as in GNU.
* **mallinfo is a snapshot of allocator metadata.** In dynamically linked
  programs the arena includes memory the dynamic loader donated to the
  allocator. Fields glibc defines but this allocator has no equivalent for
  (`smblks`, `usmblks`, `fsmblks`, `keepcost`) are 0.
* **ucontext is x86_64 only.** On other architectures the functions remain
  declared-but-undefined, exactly as in musl. `setcontext` restores x87/SSE
  control state only when the context came from `getcontext`/`swapcontext`
  (not a context handed to a signal handler, whose FP save area differs).
  An aarch64 implementation is in `kinetic/src/ucontext/aarch64-untested/`;
  it is **not built and not verified** (see the README there).
* **`makecontext` arguments** are read as 64-bit values (as glibc does), so
  pointer arguments work although POSIX says `int`.
* **`backtrace`** does not walk frame pointers; see the table above.
* **Data symbols** (`error_message_count`, `argp_program_version`, ...) are
  listed in `dynamic.list` so dynamically linked non-PIE programs share one
  copy with libc.

## Cost

Measured on x86_64 with the default `-Os`-style flags: `libc.so` is 781,536
bytes without the layer and 814,416 with it (+32,880 bytes, +4.2%). In static
linking each function is a separate object and is only pulled in if called, so
a program that uses none of it is byte-identical to one built with musl.

## Deliberately unchanged from musl

The dynamic loader name (`ld-musl-*`), the allocator, locale scope, the DNS
resolver, and the absence of NSS and `dlopen`-based plugins. Changing these
would break musl ABI compatibility or size goals.

## Not done

* **NSS / user-group lookup plugins.** Needs a design decision (a `dlopen`
  plugin model conflicts with musl's static-linking story). Not attempted.
* **Fuller `iconv`.** musl already ships many charsets; "fuller" needs a
  specific list of missing ones. Not attempted.
* **glibc fortify entry points (`__*_chk`).** Only useful for running binaries
  built against glibc headers, which also needs glibc symbol versioning and
  startup ABI. Out of scope.
* **aarch64 (and other-arch) ucontext.** Written for aarch64 but unverified;
  see above.
